# Security Policy

## Supported versions

Security fixes are provided for the latest `0.1.x` release.

## Reporting

Please use GitHub's private vulnerability reporting for this repository. Include affected versions,
reproduction steps, impact, and any suggested mitigation. Do not open a public issue for an
unpatched vulnerability.

Infra Rewind processes operational evidence locally. Reports can still contain sensitive resource
names and configuration values; review every export before sharing it.
